About HomeValue

More clarity for a big decision.

A full-stack academic project exploring how machine learning can support a home search.

The idea

Bring property discovery and price estimation into one thoughtful experience.

HomeValue is a functional demonstration built for the project “House Price Prediction for Property Purchasing Using Machine Learning.” People can explore sample property listings, save favourites, and request a property estimate that is generated by a trained regression pipeline.

The application combines a Flask web backend, SQLite account and property data, and scikit-learn models. Its listings and training prices are illustrative only.

An important note

Demonstration data, honestly presented.

The included housing dataset is synthetically generated for this project. It is not sourced from actual transactions, does not capture current market conditions, and should not be used for purchasing or investment decisions.
